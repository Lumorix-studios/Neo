## About

AgenticCoder is a desktop application focused on providing a fast, native experience with a modern UI and smooth animations.

## Current Features

* Modern desktop UI built with React + Tauri
* Responsive layout
* Cross-platform architecture
* Animated UI components (ClickSpark, PixelTransition)
* Command palette
* Info panel
* Privacy policies panel

## Planned Features

* Syntax highlighting
* Multi-tab editor
* File creation, deletion, and renaming
* Save & Save As
* Project-wide search
* Themes
* Settings

## Tech Stack

* React
* TypeScript
* Tauri
* Rust
* Vite
* Tailwind CSS

## Development

Clone the repository:

```bash
git clone https://github.com/Lumorix-studios/AgenticCoder.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run tauri dev
```
